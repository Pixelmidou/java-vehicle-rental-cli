# Java Coursework

A collection of Java practice programs and coursework exercises covering core language concepts, object-oriented programming, concurrency, file handling, and small applications. The repository contains multiple independent examples rather than one unified application.

---

## Contents

- **Java fundamentals:** variables, input/output, conditionals, methods, arrays, strings, dates, enums, exceptions, and wrapper classes
- **Object-oriented programming:** classes, inheritance, interfaces, generics, and collections
- **Streams and files:** Java Streams, reading/writing files, and CSV persistence
- **Concurrency:** threads, `Runnable`, timers, and multithreading exercises
- **GUI practice:** introductory Swing/JFrame examples
- **Vehicle-rental system:** a separate console-based project with admin/client menus, vehicle types (cars and motorcycles), rental/return workflows, and CSV storage

---

## Repository Structure

```text
Java_CourseWork/
├── Java_cores/       # Core Java examples, streams, files, GUI, and concurrency
├── Java_OOP/         # Object-oriented examples and related classes
└── Java_Uni/
    ├── tp*/          # Numbered Java exercises
    └── Projet/       # Vehicle-rental system
```

---

## Technologies

- Java (JDK 8 or newer recommended)
- Java Collections, Streams, Swing, threads, and file I/O

Each exercise or project has its own entry point; compile and run the relevant source from its folder. Some examples may require adjusting file paths to your local environment.
